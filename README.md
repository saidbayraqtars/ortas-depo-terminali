# Ortaş Depo Terminali

Ortaş Otomotiv için depo yönetimi (WMS). Vega ERP'de mal kabulü yapılan malzemeyi Android el terminaliyle
rafa kaldırma, raf transferi, ürün/raf sorgu ve sayım. İnternet çekmeyen yerlerde de çalışır.

| Klasör | İçerik |
|---|---|
| [`android/`](android/) | Terminal ve telefon uygulaması (Kotlin + Compose, Android 8.0+) |
| [`docs/API.md`](docs/API.md) | Terminal ile yönetici programındaki sunucu arasındaki sözleşme |
| [`docs/TERMINAL.md`](docs/TERMINAL.md) | Terminal kurulumu ve okuyucu ayarları (marka marka) |
| [`tasarim/`](tasarim/) | Arayüz taslağı (10 ekran) ve PNG çıktıları |

Yönetici PC programı (raf tanımı, kullanıcı/cihaz, sayım onayı, Vega bağlantısı) geliştirilecek.

APK'lar [Releases](../../releases) sayfasında. Ekranlardaki ürün, belge ve tedarikçi adları örnektir.
